PyQt5 기반의 데스크톱 GUI 애플리케이션을 개발하려고 한다.
반도체 Physical Design (Virtuoso Layout) 검증을 위한 GUI

## 목표

여러 프로젝트를 관리하는 툴이다.

화면은 좌측 영역과 우측 영역으로 나뉜다.

### 좌측 영역

- 프로젝트 목록 표시
- 프로젝트 선택

### 우측 영역

선택된 프로젝트의 설정 화면을 표시한다.

모든 프로젝트는 동일한 UI 구조를 사용한다.

프로젝트마다 다른 것은 입력값만 존재하며,
UI 구조 자체는 동일하다.

## 탭 구조

우측 영역은 다음과 같이 구성된다.

- SETTING (단일 페이지)

- CCL
  - EXTRACT
  - RUN


(실제 세부 내용은 추후 구현 예정)

## 설정 저장 기능

각 프로젝트는 독립적인 설정값을 가진다.

예시:

projects 폴더 내부
 - PROJECT1_SETTING.json
 - PROJECT2_SETTING.json

프로젝트 선택 시 저장된 설정을 자동 로드해야 한다.

## 요구사항

1. 유지보수가 쉬운 구조로 설계
2. UI와 데이터 모델 분리
3. 폴더 구조 제안
4. 클래스 구조 제안
5. JSON 기반 저장 구조 예시 제안
6. 이후 탭을 쉽게 추가할 수 있는 구조로 설계

우선 코드 작성보다 설계와 아키텍처를 설명해라.
